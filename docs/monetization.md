# Monetization

This v1 project is intentionally not monetized. It is a static, zero-dependency calculator designed to remain fast, portable, and easy to host.

Possible monetization paths in future versions include:
- paid premium rate packs,
- a hosted comparison dashboard,
- optional CSV export,
- or a professional plan with custom gateway presets.

For v1, the priority is correctness, transparency, and no tracking.
