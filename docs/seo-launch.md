# SEO launch checklist

The site includes crawlable HTML for the home page and dedicated Stripe, PayPal, and Etsy guides. The processor guides link to one another and into the interactive calculator. Query-string calculator states are for sharing and are not separate search landing pages.

## Implemented

- Absolute canonical and Open Graph URLs use the Netlify production hostname.
- `sitemap.xml` lists the home page and processor guides; `robots.txt` allows crawling and points to the sitemap.
- Netlify publishes the repository root and runs the test suite before deploys.
- Google Search Console ownership is verified using the homepage HTML tag; the sitemap was submitted and reports four discovered pages.
- Bing Webmaster Tools imported the verified site and sitemap from Google Search Console. Bing reports the sitemap as processing with no errors or warnings; its data may take up to 48 hours to appear.

## Ongoing maintenance

1. Monitor indexing and search performance in Google Search Console and Bing Webmaster Tools. Search engines control discovery and indexing, so timing and rankings cannot be guaranteed.
2. Review provider pricing sources before changing the calculator's static fee estimates.

Keep fee descriptions accurate and review source rates against provider pricing pages before publishing rate-specific claims. The current calculator values are estimates, not live-verified quotes.
